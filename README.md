# Solihull Bin Day

Unofficial Android helper for **Solihull Metropolitan Borough Council** bin collection schedules.

## Official checker
- https://digital.solihull.gov.uk/BinCollectionCalendar/
- Info: https://www.solihull.gov.uk/rubbish-and-recycling/your-collections

Enter postcode → address → calendar. Optional **email the day before** from the council site itself.

**No public open API.**

## Typical bins (mid-2026)
| Container | Role |
|-----------|------|
| Black wheelie | Household waste (moving to **fortnightly from 5 Oct 2026** for most houses) |
| Brown wheelie | Mixed recycling (fortnightly) |
| Green wheelie | Garden waste (fortnightly, subscription) |
| Food caddy | Weekly from Oct 2026 with the service change |

Put containers out by **6.00am**.

Postcodes often B90–B94, B36–B37, B26–B28, CV7 etc. (confirm on site).

## App design
Same favourites + **19:00** night-before local notifications as DudleyBinDay. After Oct 2026 treat residual like other alternate-week councils.

Base: https://github.com/kentish121-afk/DudleyBinDay  
Package: `com.example.solihullbinday`
